1. Cloud in your own words

The cloud means using computers and servers owned by another company through the internet. You rent things like storage, software, or computing power instead of buying and looking after your own servers.

2. Traditional IT, virtualization, cloud and containers

The main idea is to make computers easier to use and manage. Traditional IT used physical servers. Virtualization allowed several systems to run on one server. Cloud services let people use resources when they need them. Containers make it easier to run and move applications.

3. Deployment and service models

Deployment models describe where the systems are located and who manages them.

Service models describe how much the provider manages for you.

Microsoft 365 is an example of a public cloud service and SaaS because Microsoft provides the software through the internet.

4. Shared Responsibility Model

The Shared Responsibility Model means both the customer and the cloud provider have security responsibilities. The provider protects its systems, while the customer is responsible for things like accounts, passwords, MFA and permissions. For example, an S3 storage bucket can be accidentally made public because of a customer configuration mistake.

5. Why organisations still hesitate

One reason is that some data has to stay in certain countries because of laws and regulations. Another reason is cost, especially if a company already owns its own servers and equipment.

6. Cloud in an entry-level tech role

A helpdesk worker might help someone who cannot log in to Microsoft 365. They could also deal with a suspicious login and help reset the user's password or MFA.

7. My personal takeaway

I now understand that the cloud is basically someone else's computers that I access through the internet. I also understand that I still need to think about security when using cloud services.
